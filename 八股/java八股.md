# java八股
### **一、基础概念 (Basic Concepts)**
| **序号** | **问题**                                           | **答案要点**                                                 |
| -------- | -------------------------------------------------- | ------------------------------------------------------------ |
| 1.       | **什么是 Java**？                                  | Java 是一种由 Sun Microsystems（现已被 Oracle 收购）开发的**高级编程语言**，也是一个平台。它是一种**面向对象**的、**跨平台**的、**健壮的**、**高性能**的、**结构中立**的编程语言。 |
| 2.       | **Java 语言有哪些特点**？                          | **简单性**、**面向对象**、**跨平台/可移植性**（通过 JVM 实现）、**健壮性**（垃圾回收和异常处理）、**安全性**、**多线程**、**高性能**（通过 JIT 编译器）。 |
| 3.       | **JVM、JDK 和 JRE 有什么区别**？                   | **JVM (Java Virtual Machine)** 是执行 Java **字节码**的虚拟机，是跨平台的核心。**JRE (Java Runtime Environment)** 包含 **JVM + 核心类库**，是**运行** Java 程序的最小环境。**JDK (Java Development Kit)** 包含 **JRE + 开发工具**（如 `javac` 编译器），是**开发** Java 程序的工具包。**关系**：**JDK 包含 JRE，JRE 包含 JVM。** |
| 4.       | 说一说**跨平台是什么**？**原理**是什么？           | **跨平台**指 Java 程序编译成字节码后，可以在不同的操作系统上运行而**无需重新编译**。**原理**是 Java 源码编译成**平台无关的字节码**，然后由每个操作系统上特定实现的 **JVM** 将字节码解释或即时编译成对应平台的机器码执行。 |
| 5.       | 什么是**字节码**？采用字节码的好处是什么？         | **字节码**是 Java 源码编译后生成的**平台中立的中间代码**（`.class` 文件），面向 **JVM**。好处包括：实现**跨平台性**，通过沙箱机制提高**安全性**，以及通过 JIT 编译提高**执行效率**。 |
| 6.       | 为什么有人说 Java 是 "**编译和解释并存**" 的语言？ | Java 运行分为两个阶段：1. **编译**：源码被 **Javac** 编译成字节码。2. **执行**：字节码在 **JVM** 中**解释**执行，同时 JVM 为了性能会将热点代码**即时编译 (JIT)** 成机器码。因此，它兼具编译和解释的特性。 |

### **二、基础语法 (Basic Syntax)**



| **序号** | **问题**                                            | **答案要点**                                                 |
| -------- | --------------------------------------------------- | ------------------------------------------------------------ |
| 7.       | Java 有哪些**数据类型**？                           | 分为两大类：**基本数据类型**（8 种：`int, long, float, double, byte, short, char, boolean`）和**引用数据类型**（类、接口、数组）。 |
| 8.       | **自动类型转换、强制类型转换**了解吗？              | **自动转换**（隐式）：低精度 $\rightarrow$ 高精度，自动进行。**强制转换**（显式）：高精度 $\rightarrow$ 低精度，需要使用 `(目标类型)`，**可能导致精度丢失**。 |
| 9.       | 什么是**自动拆箱/装箱**？                           | **装箱**：将**基本数据类型**自动转换为对应的**包装器类型**（如 `int` $\rightarrow$ `Integer`）。**拆箱**：将**包装器类型**自动转换为对应的**基本数据类型**。 |
| 10.      | **& 和 &&** 有什么区别？                            | **`&`** 是**非短路**逻辑与（两边都执行），也可作位运算符。**`&&`** 是**短路**逻辑与，如果左侧为 `false`，则右侧表达式**不再执行**。 |
| 11.      | **switch 语句**能否用在 `byte/long/String` 类型上？ | 可以用于 `byte, short, int, char`，以及 **`String`**（JDK 7+）和 **枚举 (Enum)**。**不能**用于 `long, float, double, boolean`。 |
| 12.      | **break、continue、return** 的区别及作用？          | **`break`**：立即跳出当前的 `switch` 或循环。**`continue`**：结束本次循环，进入下一次迭代。**`return`**：结束当前方法的执行，将控制权返回调用方。 |
| 13.      | 用效率最高的方法**计算 2 乘以 8**？                 | 使用位运算：**`2 << 3`**（左移 3 位），相当于乘以 $2^3$。    |
| 14.      | 说说**自增自减运算符**？                            | **前缀式** (`++i` / `--i`)：**先改变**变量的值，**再使用**新值参与运算。**后缀式** (`i++` / `i--`)：**先使用**原值参与运算，**再改变**变量的值。 |
| 15.      | **float** 是怎么表示小数的？ (补充)                 | 遵循 **IEEE 754 标准**，用 **1 位符号位、8 位指数位、23 位尾数位**表示。由于尾数位有限，**无法精确表示所有小数**，存在精度损失。 |
| 16.      | 讲一下**数据准确性**是怎么保证的？ (补充)           | 对于商业和金融计算，使用 **`java.math.BigDecimal`** 提供任意精度的计算。在多线程环境下，使用 `synchronized`、`Lock` 或 `volatile` 等保证**数据一致性**和**原子性**。 |

### **三、面向对象 (Object-Oriented)**



| **序号** | **问题**                                                     | **答案要点**                                                 |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 17.      | **对象和面向过程**的区别？                                   | **面向过程**：以**过程**为中心，强调**步骤**，数据与操作分离。**面向对象**：以**对象**为中心，强调**谁来做**，将数据和操作封装在一起。 |
| 18.      | **面向对象编程**有哪些**特性**？                             | **封装 (Encapsulation)**、**继承 (Inheritance)**、**多态 (Polymorphism)**。 |
| 19.      | **多态**解决了什么问题？ (补充)                              | 增强程序的可**扩展性**、可**维护性**，通过父类引用操作子类对象，**屏蔽了子类间的差异**，**降低耦合度**。 |
| 20.      | **重载和重写**的区别？                                       | **重载 (Overloading)**：发生在**同一个类**中，方法名相同，**参数列表必须不同**。**重写 (Overriding)**：发生在**父子类**中，方法名、参数列表**必须相同**。 |
| 21.      | 访问**修饰符 public、private、protected** 以及**默认时**的区别？ | **`private`**：仅本类可见。**默认 (default)**：本包可见。**`protected`**：本包及**跨包子类**可见。**`public`**：所有地方可见。 |
| 22.      | **this 关键字**有什么作用？                                  | 1. **区分同名成员变量**。2. **调用本类构造方法**（`this(...)`）。3. **返回当前对象**。 |
| 23.      | **抽象类和接口**有什么区别？                                 | **抽象类**：可以有普通方法，单继承，有构造器，旨在**代码复用**。**接口**：只能有多抽象方法（JDK 8+ 默认/静态方法），**多实现**，无构造器，旨在**定义规范**。 |
| 24.      | **成员变量与局部变量**的区别有哪些？                         | **成员变量**：定义在类中，有**默认值**，存储在**堆**中，生命周期随对象。**局部变量**：定义在方法内，**无默认值**（必须初始化），存储在**栈**中，生命周期随方法/代码块。 |
| 25.      | **static 关键字**有什么作用？                                | 修饰的成员（变量、方法、代码块）属于**类级别**，被所有对象**共享**，可以通过**类名**直接访问，随类加载而创建。 |
| 26.      | **final 关键字**有什么作用？                                 | 修饰**类**：不可被继承。修饰**方法**：不可被重写。修饰**变量**：**值**（基本类型）或**引用本身**（引用类型）不可变。 |
| 27.      | **final、finally、finalize** 的区别？                        | **`final`**：修饰符（不可变）。**`finally`**：异常处理块（**一定**执行）。**`finalize()`**：`Object` 方法（GC **尝试**在回收前调用）。 |
| 28.      | **== 和 equals()** 的区别？                                  | **`==`**：比较**基本类型的值**或**引用类型的地址**。**`equals()`**：默认同 `==`，但**重写后**用于比较对象的**逻辑内容**。 |
| 29.      | 为什么重写 `equals` 时**必须重写 `hashCode`** 方法？         | 为了遵守约定：如果两个对象 `equals` 相等，则它们的 `hashCode` **必须相等**。这能确保对象在 **`HashMap/HashSet`** 等基于哈希的集合中能正确地查找和存储。 |
| 30.      | Java 是**值传递**，还是**引用传递**？                        | **Java 只有值传递 (Pass-by-Value)**。引⽤类型的变量存储的是对象的地址，⽽不是对象本身。因此，引⽤类型的变量在传递时，传递的是对象的地址，也就是说，传递的是引⽤的值。 |
| 31.      | 说说**深拷贝和浅拷贝**的区别？                               | **浅拷贝**：只复制基本类型值和**引用地址**，新旧对象**共享**内部的引用对象。**深拷贝**：**递归地复制**对象内部的所有引用对象，新旧对象完全**独立**。拷⻉的实现⽅式为：实现 Cloneable 接⼝并重写 clone() ⽅法；拷⻉的实现⽅式有：⼿动复制所有的引⽤对象，或者使⽤序列化与反序列化。 |
| 32.      | Java **创建对象**有哪几种方式？                              | 1. 使用 **`new`** 关键字。2. 使用**反射**（`Class/Constructor.newInstance()`）。3. 使用 **`clone()`** 方法。4. 使用**反序列化**：过序列化将对象转换为字节流，再通过反序列化从字节流中恢复对象。需要实现Serializable 接⼝（`ObjectInputStream.readObject()`）。 |
| 33.      | **String** 是基本数据类型吗？可以被继承吗？                  | **不是**，它是 `java.lang.String` 类，属于引用数据类型。**不能**，因为它被 **`final`** 关键字修饰。 |
| 34.      | **String 和 StringBuilder、StringBuffer** 的区别？           | **`String`**：**不可变**，线程安全。**`StringBuffer`**：**可变**，**线程安全**（通过 `synchronized`）。**`StringBuilder`**：**可变**，**线程不安全**，**性能最高**，当遇到⼤量字符串连接时，就⽤ StringBuilder，它不会⽣成很多新的对象。 |
| 35.      | `String str1 = new String("abc")` 和 `String str2 = "abc"` 的区别？ | `str1`：在**堆**中创建对象。`str2`：在**字符串常量池**中创建或引用对象。`str1 == str2` 结果为 `false`。 |
| 36.      | **String 是不可变类吗**？字符串拼接是如何实现的？            | **是**，一旦创建，其值不可更改。**拼接实现**：在 JDK 8 及以前，编译器通过 **`StringBuilder.append()`** 实现；JDK 9+ 使用 **`StringConcatFactory`** 实现。 |
| 37.      | `Integer a=127; Integer b=127; Integer c=128; Integer d=128;` 相等吗？ | **`a == b` 为 true**。因为 Java 对 `Integer` 包装类有 **-128 到 127** 的**缓存**，所以引用的是同一对象。**`c == d` 为 false**。因为 128 超出了缓存范围，每次都创建了新对象。Integer 缓存的主要⽬的是优化性能和内存使⽤。对于⼩整数的频繁操作，使⽤缓存可以显著减少对象创建的数量 |
| 38.      | **String 怎么转成 Integer 的**？原理？                       | 通过 **`Integer.parseInt(str)`** 或 **`Integer.valueOf(str)`**。原理是遍历字符串，将字符转换为数字，并进行 **10 进制的加权求和**，不过计算⽅式有点反常规，是⽤负的值累减。 |
| 39.      | **Object 类的常见方法**？| 对象比较（equals, hashCode）、对象拷贝（clone）、对象转字符串（toString）、多线程调度（wait, notify, notifyAll）、反射（getClass）和垃圾回收（finalize）。                                                              |



### **四、异常、I/O 与 序列化**



| **序号** | **问题**                                                 | **答案要点**                                                 |
| -------- | -------------------------------------------------------- | ------------------------------------------------------------ |
| 40.      | Java 中**异常处理体系**？                                | Java 中的异常处理机制⽤于处理程序运⾏过程中可能发⽣的各种异常情况，通常通过 try-catch-finally 语句基于 **`Throwable`**。分为：**`Error`**（系统级，不处理）和 **`Exception`**。`Exception` 分为**受检异常**（编译时强制处理，如 `IOException`）和**运行时异常**（`RuntimeException`，不强制处理，如 `NPE`）。 |
| 41.      | IO 流用到了什么**设计模式**？Java 缓冲区溢出，如何预防？ | throw 关键字来实现。**装饰器模式**（如 `BufferedInputStream`）、**适配器模式**。预防**栈溢出**需要避免无限递归或将递归改为迭代。 |
| 42.      | **异常的处理方式**？                                     | **捕获**（`try-catch-finally`）和 **抛出**（`throws` 关键字或 `throw` 语句）。 |
| 43.      | 三道经典异常处理代码题？                                 | 考察要点：1. **`finally` 块**（除 `System.exit()` 外）**总会执行**。2. `finally` 中的 `return` 会**覆盖** `try` 或 `catch` 中的返回值。3. `finally` 中抛出的异常会**覆盖**其他异常。 |
| 44.      | Java 中 **IO 流分为几种**？                              | **按数据类型**：**字节流**（`InputStream`/`OutputStream`）和**字符流**（`Reader`/`Writer`）。**按流向**：输入流和输出流。 |
| 45.      | 既然有了字节流，为什么还要有**字符流**？                 | 字符流在底层实现**自动处理字符集编码和解码**，使得文本处理更简单，避免了字节流处理多字节字符集时可能出现的**乱码**问题。 |
| 46.      | **BIO、NIO、AIO** 之间的区别？                           | **BIO (Blocking)**：**阻塞**，**一连接一线程**。**NIO (Non-blocking)**：**非阻塞**，使用 **Selector** 实现**一线程管理多连接**。**AIO (Asynchronous)**：**异步**，I/O 操作完成后**回调通知**。 |
| 47.      | 什么是**序列化**？什么是**反序列化**？                   | **序列化**：将 **Java 对象**转换成**字节序列**。**反序列化**：将**字节序列**恢复成 **Java 对象**。被序列化的类需实现 `Serializable` 接口。 |
| 49.      | 了解 **Socket 网络套接字**吗？ (补充)                    | **`Socket`** 是网络通信的**抽象端点**，用于应用程序之间通过网络进行双向通信。Java 通过 `java.net.Socket`（客户端）和 `java.net.ServerSocket`（服务端）实现网络连接。 |

### **五、泛型、注解、反射与 JDK 8+ 特性**



| **序号** | **问题**                                    | **答案要点**                                                 |
| -------- | ------------------------------------------- | ------------------------------------------------------------ |
| 50.      | **Java 泛型**了解么？（泛型类、接口、方法） | 实现**参数化类型**。泛型类：`class Box<T>`。泛型接口：`interface Generator<T>`。泛型方法：`<T> T method(...)`。 |
| 50.      | 什么是**泛型擦除**？为什么要类型擦除呢？    | 泛型类型信息在**编译期**会被**擦除**（替换为 `Object` 或其边界）。目的是保持与 **JDK 1.5 之前的 JVM 向后兼容**。 |
| 51.      | 说一下你对**注解**的理解？                  | 一种**元数据**形式，为代码提供**非侵入式的附加信息**。注解本身不影响代码逻辑，但可被编译器或工具（如反射）读取和处理。 |
| 52.      | 什么是**反射**？应用？原理？                | **运行时**动态获取并操作类（构造器、方法、字段）的机制。**原理**基于 **`java.lang.Class`** 对象。应用于 **Spring/MyBatis 等框架**的依赖注入、AOP、动态代理等。 |
| 53.      | **JDK 1.8 都有哪些新特性**？                | **Lambda 表达式**、**Stream API**、**接口默认方法**、**`Optional` 类**、**新时间日期 API** (`java.time`)。 |
| 54.      | **Lambda 表达式**了解多少？                 | **函数式编程**特性，用**简洁语法**表示**匿名内部类**（针对**函数式接口**）。语法：`(参数列表) -> { 表达式主体 }`。 |
| 55.      | **Optional** 了解吗？                       | **容器对象**，用于**封装可能为空的值**，旨在以更安全、更优雅的方式处理**空指针异常 (NPE)**。常用方法：`orElse()`, `orElseGet()`, `isPresent()`。 |
| 56.      | **Stream 流**用过吗？                       | 用于**集合数据**的**声明式处理**。支持**链式操作**，分为**中间操作**（`filter, map`）和**终止操作**（`collect, forEach`），具有**惰性执行**的特点。 |
